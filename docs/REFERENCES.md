# Referencias consultadas

Esta demo tiene una implementación acotada propia. Los siguientes proyectos se consultaron durante la investigación privada para entender los problemas habituales del análisis de registros de motor y telemetría. No son dependencias de ejecución y esta exportación no incluye su código, sus datos ni sus recursos gráficos.

- [ECUxPlot](https://github.com/nyetlabs/ecuxplot): herramienta de gráficos y análisis de registros ECU.
- [UltraLog](https://github.com/ClassicMiniDIY/UltraLog): flujos de lectura y análisis de registros.
- [TuneAssist](https://github.com/allantaylor8907/tuneassist): herramienta revisada durante la investigación. Su código upstream y el adaptador correspondiente quedan fuera de esta demo.
- [FuelTune Analyzer](https://github.com/leechardes/fueltune-analyzer): referencia para flujos de importación y análisis.

Estos enlaces reconocen antecedentes y fuentes consultadas. No son recomendaciones comerciales ni afirmaciones de que esta demo tenga las mismas funciones, compatibilidad o resultados.
