# Límites de la demo

- Todos los registros que se muestran se generan de forma sintética dentro de la aplicación. Ningún valor procede de un vehículo, una ECU, un logger o un dinamómetro real.
- Las curvas de torque y potencia son ejemplos para probar el software. El cálculo de potencia no valida un modelo de motor.
- Que dos señales tengan el mismo nombre o una unidad parecida no demuestra que representen la misma medición, carga, marcha, condición ambiental o método de prueba.
- ECU/logger y dinamómetro son fuentes de evidencia distintas. Esta demo bloquea su comparación directa.
- Declarar que dos archivos están relacionados no demuestra que sus relojes estén sincronizados.
- La aplicación no escribe, modifica ni programa una ECU; tampoco diagnostica fallas ni emite recomendaciones de calibración.
- Que las pruebas automáticas terminen correctamente solo confirma el comportamiento del software cubierto por ellas. La validación real requiere datos autorizados y revisión de especialistas.
- La demo utiliza escenarios sintéticos incluidos y no importa archivos CSV del usuario.
