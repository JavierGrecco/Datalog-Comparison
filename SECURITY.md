# Política de seguridad

## Alcance

Datalog Comparison es un prototipo experimental de ejecución local con datos sintéticos. No está diseñado para conectarse a una ECU, controlar hardware, procesar datos de clientes ni operar en producción.

## Reporte responsable

No publiques vulnerabilidades explotables, credenciales, información personal, archivos de clientes ni registros reales en un issue público.

Para coordinar la revisión de un posible problema de seguridad, contactá al propietario del repositorio desde su perfil de GitHub. Si la función de reporte privado de vulnerabilidades está habilitada en el repositorio, también puede utilizarse ese canal.

No se establece un SLA de respuesta ni se ofrece una garantía de seguridad para uso productivo.

## Datos de prueba

Los ejemplos del repositorio son sintéticos. No agregues archivos ECU/logger, exportaciones de dinamómetro, patentes, VIN, datos de clientes ni rutas locales a commits o issues públicos.
